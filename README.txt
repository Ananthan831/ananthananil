ANANTHAN A — FORMAL PORTFOLIO

Files
- index.html — main portfolio page
- CSS.css — responsive layout, dark/light themes, and animation styling
- JS BASIC.js — navigation, theme persistence, scroll reveals, and particle animation
- 1686996350897.JPG — profile photo

Design notes
- Dark theme is the default.
- The theme switcher still allows an explicit light theme and remembers that choice in the browser.
- The hero includes a custom canvas particle animation that disperses and converges into the letter A, with pause and replay controls.
- The animation is implemented without third-party JavaScript libraries.
- The contact form uses Netlify Forms attributes and can be enabled when deployed on Netlify.

Deployment
1. Extract all files from the ZIP.
2. Upload the folder to a static host such as Netlify, GitHub Pages, Vercel, or any standard web server.
3. Keep the HTML, CSS, JS, and JPG files in the same directory.
